# Physical AI & Humanoid Robotics

A comprehensive book on Physical AI and Humanoid Robotics, covering ROS 2, Digital Twins (Gazebo + Unity), NVIDIA Isaac Platform, and Vision-Language-Action (VLA) pipelines.

## Project Structure

- `docs/`: All book content in markdown format.
- `docusaurus.config.js`: Docusaurus site configuration.
- `sidebars.js`: Defines the sidebar navigation.
- `src/css/custom.css`: Custom CSS styles.

## Development

To start the Docusaurus development server:

```bash
npm install
npm start
```

## Deployment

This book is designed to be deployed to GitHub Pages.
